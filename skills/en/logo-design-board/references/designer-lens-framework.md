# Designer Lens Framework

Use this reference when building a logo design board from public designer methods.

## Source Priority

Prefer evidence in this order:

1. First-party books, essays, talks, interviews, portfolios, lectures, and case studies.
2. Studio or client case studies with process notes.
3. Recorded critiques, teaching material, or long-form conversations.
4. Credible third-party analysis, biographies, reviews, or museum materials.
5. Social snippets and short quotes only as weak supporting evidence.

Avoid mood-board scraping, image-only inspiration, unattributed quote collections, and style imitation prompts.

## What to Extract

Extract judgment, not costume:

- Recurring design principles.
- Questions the designer seems to ask before drawing.
- What they simplify, exaggerate, reject, or preserve.
- How they decide whether a mark is finished.
- Typical failure modes they would criticize.
- How their work behaves across media and scale.

Do not reduce a designer to colors, shapes, fashionable adjectives, or catchphrases.

## Three-Part Validation

Treat a principle as a strong lens only when it passes all three checks:

1. Recurs across at least two works, talks, or contexts.
2. Generates decisions for a new logo problem.
3. Differs from generic good-design advice.

If a principle passes only one or two checks, use it as a light critique rule rather than a core lens.

## Lens Card Format

Build each lens as a compact card:

```markdown
### [Designer] lens
Core bias: [what this lens optimizes for]
Best questions:
- [question 1]
- [question 2]
Positive pressure:
- [what this lens will improve]
Red flags:
- [what this lens will reject]
Logo implications:
- [mark type, geometry, typography, scale, color, system behavior]
Failure mode:
- [how overusing this lens can hurt the work]
Evidence:
- [source or observed recurring pattern]
```

## Default Board

Use these lenses when the user has not named specific designers:

### Paul Rand lens

Core bias: a logo should hold a memorable idea in a simple form.

Useful questions:

- Is there one clear idea, or only decoration?
- Can the mark survive as a small black shape?
- Is there wit, surprise, or memory without clutter?

Risk when overused: over-clever symbols that need explanation.

### Massimo Vignelli lens

Core bias: a logo should behave as part of a disciplined, lasting identity system.

Useful questions:

- Is the form too trendy to survive five years?
- Does the typography have order and restraint?
- Does the mark work inside a larger grid, layout, and signage system?

Risk when overused: sterile reduction that erases personality.

### Paula Scher lens

Core bias: identity can carry voice, scale, cultural energy, and typographic attitude.

Useful questions:

- Does the mark have presence in the world, not only in a mockup?
- Does typography express the brand's voice?
- Is the system expandable into campaigns, environments, and motion?

Risk when overused: expressive noise that weakens small-size recognition.

## Optional Lenses

### Saul Bass lens

Use for narrative, motion-friendly, cinematic, or silhouette-driven identity work.

Risk when overused: poster-like storytelling that is not flexible enough for daily brand use.

### Michael Bierut lens

Use for stakeholder-heavy, public-facing, institutional, or system-driven identity work.

Risk when overused: context solves everything, but the mark itself becomes too polite.

## Hybrid Board Rules

- Use three core lenses by default.
- Add at most one optional lens unless the user explicitly asks for a larger board.
- Make lenses argue with each other. A board that agrees on everything is not useful.
- Let strategy decide the winner; do not average every lens into a bland compromise.
